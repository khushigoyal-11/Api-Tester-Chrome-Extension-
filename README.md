## About The Project

Api Tester was born out of the need for a **single-pane API testing** tool in Chrome, without the overhead of switching apps. It combines:

- **URL + Method** selector  
- **5 tabs**: Params, Authorization, Headers, Body, Scripts  
- **Real-time JSON** response viewer  
- **Pre-request** & **post-response** scripting hooks  

No more juggling Postman windows—test your endpoints in under **5 seconds** and get back to coding.
